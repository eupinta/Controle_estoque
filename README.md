 Sistema de Controle de Estoque

Este é um sistema simples de controle de estoque desenvolvido em Python, com foco em praticidade e facilidade de uso. Ideal para projetos pequenos ou estudos.

 Funcionalidades

- Cadastro de produtos com código gerado automaticamente
- Registro de **entrada** e **saída** de produtos
- Consulta de quantidade atual no estoque
- Menu interativo via terminal
